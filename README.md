# 📰 Simple Blog Layout Using Bootstrap 5

## 🎯 Objective
Create a responsive blog webpage using **Bootstrap 5 CDN**, featuring a **navbar**, **blog cards**, and a **footer** with social icons.

---

## 🛠️ Tools & Technologies
- **VS Code** – Code Editor  
- **Bootstrap 5 CDN** – Frontend Framework  
- **HTML5, CSS3** – Structure & Styling  
- **Browser (Chrome/Edge/Firefox)** – For Testing  

---


## 🚀 How to Run This Project

1. **Clone or Download** this repository  
   ```bash
   git clone https://github.com/<your-username>/simple-blog-bootstrap.git
2. Open the Project Folder

cd simple-blog-bootstrap


3. Open index.html in Browser

Simply double-click index.html, or

Use VS Code Live Server Extension for auto reload.

---

## 🧱 Features ##

✅ Responsive Navbar – With brand and navigation links
✅ Blog Cards Section – Each card contains an image, title, and “Read More” button
✅ Bootstrap Grid System – Automatically adjusts layout for all screen sizes
✅ Footer with Social Icons – Clean and simple using Bootstrap Icons
✅ Mobile Friendly – Fully responsive on all devices
